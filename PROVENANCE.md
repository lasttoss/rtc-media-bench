# Provenance

What in this repository was written here, and what was taken from somewhere else.

## Vendored, with attribution

- **`lab/sfu/`** - upstream [pion/example-webrtc-applications `sfu-ws`](https://github.com/pion/example-webrtc-applications)
  at commit `6b76bbb5518f`, **MIT** (see `lab/sfu/LICENSE`). The media path is upstream's, untouched.
  A local patch adds ICE configuration flags; `lab/sfu/patches/0001-ice-config.patch` is the diff and
  `make verify-patch` re-derives it from upstream and fails on any difference. `lab/sfu/README.md`
  says what changed and why.
- **`testdata/sample.ivf`** - a one-second 160x120 clip generated by ffmpeg (`libvpx`) for this
  repository, so the harness publishes real VP8 frames without a codec dependency. The command that
  produced it is in `Makefile`'s `sample` target and can be re-run.

## Written for this repository

The harness (`cmd/bench`, `internal/`), the chart, the lab scripts, the runbook, the figure and the
generator for it. No code from any employer, no internal chart, no hostname, domain, room name or
piece of production configuration. The lab's faults are reproduced from public behaviour of ICE,
Services and NetworkPolicies, not from an incident report.

## What this repository does not claim

- Not a fork of an SFU and not a media-quality benchmark: no codec work, no TURN, no echo testing.
  It measures join, RTT, addresses and packet counts through a real WebRTC stack, and says so.
- The numbers in the README come from one machine over loopback. They are reproducible with
  `make measure`, and they are not a capacity claim about any cluster.
